# C++ Calculator
This is a calculator I made in C++ while learning and practicing the language.

# Features:
* Addition, subtraction, multiplication, and division
* Powers and modulo
* Square root, square, logarithm, and absolute value
* Sin, cos, and tan
* Decimal numbers
* Use `ans` to use the previous answer
* Handles invalid inputs and some math errors
* Can keep running calculations until you choose to stop

# What I practiced: 
I practiced using functions, loops, conditionals, strings, exception handling, and working with the `<cmath>` library.

This is a small learning project I made to improve my C++ skills.
